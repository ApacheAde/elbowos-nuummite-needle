# Nuummite Needle

Full-colour **Python 3** neon thread-the-eye arcade for [ElbowOS](https://x.com/ElbowOS).

Steer a gold filament through drifting nuummite needle-eyes. Thread the hollow for combo points. Clip the rim and the thread snaps.

## Play

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 nuummite_needle.py --play
```

Controls: **A / D** or arrows to steer, **R** reset, **Esc** quit.

## Autoplay reel

```bash
python3 nuummite_needle.py --record
```

Writes a 15s 1080×1920 H.264 MP4 (title + score + `x.com/ElbowOS` overlay).
